# Documentation

This directory contains the project documentation for Apple Calendar MCP.

- [Product Specification](Product%20Specification.md): product goals, features, UX expectations, and roadmap.
- [Technical Specification](Technical%20Specification.md): architecture, MCP contract, data model, tool behavior, and performance rules.
- [Security Specification](Security%20Specification.md): threat model, permission model, write safety, privacy, and auditability.
- [Development Guide](Development%20Guide.md): implementation rules, contributor workflow, and testing expectations.
- [Installation Guide](Installation%20Guide.md): source install, native setup app flow, client config generation, and troubleshooting.
- [Release Checklist](Release%20Checklist.md): release packaging, checksums, security review, performance review, and public release gates.
- [client-configs](client-configs/README.md): generated MCP client config templates and validation instructions.

See the root [`README.md`](../README.md), [`SECURITY.md`](../SECURITY.md), and
[`CHANGELOG.md`](../CHANGELOG.md) for the project overview, security policy,
and release history.
