# Apple Calendar MCP — заметки для агентов

**Перед любой работой по проекту откройте [`ISSUES.md`](./ISSUES.md).**
Там зафиксированы известные проблемы работоспособности и безопасности
(аудит от 2026-11-22), их приоритеты, доказательства и команды проверки.
На этом Mac все тесты прошли после сборки Swift-хелпера.

Быстрый старт проверки:

```sh
npm install
npm run build
npm run helper:bundle          # обязателен для тестов конфигов
node --test tests/*.test.mjs
npm audit --omit=dev
```

Ключевая документация: `README.md`, `SECURITY.md`, `docs/`.
Правила безопасности живут в `SECURITY.md` — сверяйтесь с ними при изменениях.
